1 - Integracion de Bootstrap

Use estas lineas para poder usar Bootstrap dentro de mi pagina

La primera linea carga los estilos y va dentro del head 

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
rel="stylesheet">

La segunda linea carga el JavaScript y la puse antes de cerrar el body 

<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>

Use el JavaScript porque algunas cosas como el menu y el collapse necesitan que este cargado para funcionar

Al principio pense que con solo poner el CSS ya funcionaba todo Cuando el collapse no respondia revise Network y me di cuenta que tambien necesitaba el bundle de JavaScript

2 - Breakpoints

Los use para que la pagina cambie dependiendo del tamaño de la pantalla

En mis proyectos use principalmente md y lg

Breakpoint Prefijo Tamaño
xs Sin prefijo Menor a 576 px
sm col-sm- Desde 576 px
md col-md- Desde 768 px
lg col-lg- Desde 992 px
xl col-xl- Desde 1200 px
xxl col-xxl- Desde 1400 px

Use md para mostrar dos proyectos por fila y lg para mostrar tres

Al principio me confundia con md y lg porque no recordaba desde que tamaño empezaba cada uno Lo revise cambiando el ancho de la pagina en DevTools y viendo cuando cambiaban las columnas

3 - Rejilla

Use la rejilla para ordenar las tarjetas de mis proyectos

La estructura que use fue container, row y col 

<main class="container">

    <section class="row">

        <article class="col">
            contenido
        </article>

    </section>

</main>

En mi pagina de proyectos use esta combinacion 

<section class="row row-cols-1 row-cols-md-2 row-cols-lg-3 g-4">
    proyectos
</section>

row-cols-1 hace que se vea un proyecto por fila

row-cols-md-2 hace que desde md se vean dos proyectos

row-cols-lg-3 hace que desde lg se vean tres proyectos

g-4 lo use para dejar espacio entre las tarjetas

Lo que mas me costo fue entender como cambiar de una columna a dos y luego a tres Lo probe desde DevTools cambiando el tamaño de la pantalla hasta que vi los dos cambios

7 - Navbar y Toggler

Use navbar para crear la barra que esta arriba de mi pagina

La use para poder moverme entre mi hoja de vida, proyectos y documentacion 

<nav class="navbar navbar-expand-md navbar-dark bg-dark">

    <button class="navbar-toggler"
            type="button"
            data-bs-toggle="collapse"
            data-bs-target="#menu">

        <span class="navbar-toggler-icon"></span>

    </button>

    <section class="collapse navbar-collapse" id="menu">
        enlaces
    </section>

</nav>

navbar-expand-md hace que el menu se vea completo desde una pantalla mediana

navbar-toggler hace que aparezca el boton de tres lineas cuando la pantalla es pequeña

data-bs-target="#menu" tiene que tener el mismo nombre que id="menu"

Al principio el boton de tres lineas aparecia pero no abria el menu Revise en Elements y vi que data-bs-target y el id del menu tenian que tener el mismo nombre

8 - Formulario

Use las clases de Bootstrap para que los campos del formulario se vieran ordenados

Codigo

</label>

       class="form-control"

form-label lo use para el label

form-control lo use para darle el estilo de Bootstrap al input

required no es de Bootstrap, lo use para hacer obligatorio el campo

Una vez probe el formulario sin required y dejaba enviar el campo vacio Revise el input en Elements y vi que faltaba ese atributo

9 - Collapse

Use collapse para que al presionar Ver detalles apareciera la informacion debajo del proyecto

Tambien hace que al volver a presionar el boton la informacion se oculte

Se desarrollo en C# para llevar el control de productos, ventas y existencias

Codigo 

<button class="btn btn-primary"
        type="button"
        data-bs-toggle="collapse"
        data-bs-target="#ejemploDetalle">

    Ver detalles

</button>

<p class="collapse mt-3" id="ejemploDetalle">
    Se desarrollo en C# para llevar el control de productos, ventas y existencias
</p>

data-bs-toggle="collapse" le indica a Bootstrap que el boton va a mostrar u ocultar algo

data-bs-target="#ejemploDetalle" busca el elemento que tenga id="ejemploDetalle"

Lo que mas me costo fue entender que data-bs-target tenia que conectarse con el id Cuando no aparecia la informacion revise ambos valores en Elements y ahi pude ver el error

11 - Errores que pueden pasar

CDN mal escrito

Si la direccion del CDN esta mal la pagina puede cargar pero sin los estilos de Bootstrap

Para revisarlo puedo entrar a DevTools y luego a Network para ver si el archivo cargo bien

data-bs-target y id diferentes

Si los nombres no son iguales puedo presionar el boton pero no va a pasar nada 

data-bs-target="#detalle1"

id="detalle1"

Para revisarlo puedo entrar a Elements y comparar los dos nombres

Falta el JavaScript de Bootstrap

Si falta bootstrap.bundle.min.js los estilos pueden verse bien pero el collapse y el menu no van a funcionar

Puedo revisarlo en Network para ver si el archivo JavaScript realmente cargo

Si algo se ve bien pero no responde cuando le doy click revisaria primero el target, el id y el JavaScript
